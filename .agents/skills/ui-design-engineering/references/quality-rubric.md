# Visual quality rubric

Rate each applicable category from 0 (fails) to 4 (meets the brief) and cite evidence for each rating. Compute the weighted percentage as the sum of weight times rating divided by 4. If a category is untested, list the coverage gap and leave the total provisional. Use the score to compare revisions under matching conditions.

| Category | Weight | Evidence |
|---|---:|---|
| Usability and task clarity | 25% | Essential task completion and clear primary actions |
| Visual hierarchy and typography | 20% | Legibility, heading structure, density, and wrapping |
| Design consistency | 15% | Coherent use of approved tokens and components |
| Responsive behavior | 15% | Essential controls visible and operable at supported widths |
| Accessibility | 15% | Keyboard, focus, naming, contrast, and form semantics |
| Interface states and feedback | 10% | Clear and consistent empty, loading, error, disabled, and success states |

Any broken essential navigation, functionality loss, unauthorized disclosure, critical keyboard barrier, unusable mobile workflow, or insufficient contrast on essential controls blocks completion regardless of the score. Aim for WCAG 2.2 AA and report the limits of automated checks.
